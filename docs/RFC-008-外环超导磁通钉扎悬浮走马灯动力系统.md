## 1. 系统宏观拓扑与空间几何约束

外围走马灯环绕七级退台方坛外围，是祭坛向外部红尘世界展开的视觉与历史界面。

### 1.1 几何参数与开间账目

* **外环半径与周长**：基准回转半径 $R = 24.0\text{ m}$（外径 $D = 48.0\text{ m}$），圆周长 $L = 2\pi R \approx 150.796\text{ m}$。
* **六十四卦开间分划**：圆周等分为 $N = 64$ 个标准开间，每开间对应圆心角 $\Delta \theta = \frac{2\pi}{64} = 5.625^\circ \approx 0.09817\text{ rad}$，单开间弧长 $\Delta s = \frac{150.8}{64} \approx 2.356\text{ m}$。
* **虚实比例（1:3 空间透光律）**：
  * **实位（16 面茶灯）**：挂载 16 幕巨幅透光娟帛茶屏（对应锁侠原著《茶史五绝赋》16 卷章）。
  * **虚位（48 个空开间）**：透空率 $\frac{48}{64} = 75\%$。外部观礼者透过虚位可毫无阻挡地直视内部七级方坛与无极天光。
* **中央神圣净空约束**：$r \in [0, 18.0\text{ m}]$ 区间为绝对净空区，严禁任何机械连杆或电缆跨越。整个外环必须实现**自闭合环形自承重结构**。

## 2. 物理学内核：高温超导磁通钉扎（西南交大技术架构解耦）

系统彻底解耦**“悬浮（Levitation）”**、**“导向（Guidance）”**与**“推进（Propulsion）”**三大物理自由度：

### 2.1 悬浮与导向：完全零外电功耗的天然势阱（Flux Pinning）

1. **永磁导轨（Stator Track）**：
   地面铺设同心双环钕铁硼（NdFeB）永磁阵列，充磁方向构成 Halbach 磁体构型，在轨道上方形成高梯度环形空间磁场 $\mathbf{B}(r, z)$。永磁轨道本身**完全不通电、无主动励磁**。
2. **高温超导块材（Rotor Cryostats）**：
   浮环底部均布 64 组深冷隔热杜瓦罐，内置 YBCO（钇钡铜氧，$\text{YBa}_2\text{Cu}_3\text{O}_{7-\delta}$）高温超导块材，工质为 77K 液氮（$\text{LN}_2$）。
3. **磁通钉扎自稳定机制**：
   在轨道上方指定高度注入液氮降温，超导体越过临界温度 $T_c \approx 93\text{ K}$ 进入超导态（场冷过程 Field Cooling）。超导体内部缺陷将外部磁力线强力“钉扎”：
   * **垂直抗压抗拉刚度**：浮环向下受压或向上受拉时，超导块内部自发激发出无阻超导屏蔽电流，产生强烈的排斥力或吸引力：
     $$F_z = -K_z (z - z_0) - C_z \dot{z}$$
   * **径向抗横移刚度**：浮环向内或向外偏移时，磁通钉扎产生自恢复力矩：
     $$F_r = -K_r (r - R) - C_r \dot{r}$$
   * **周向切向自由度**：由于永磁轨道沿圆周 $\theta$ 方向具有轴对称性，磁场在圆周方向梯度 $\frac{\partial \mathbf{B}}{\partial \theta} \approx 0$。超导块在前进方向感受不到势垒，**切向摩擦阻力仅由微弱的残余磁滞损耗和空气阻力决定**。
   * **至高法则**：**负责悬浮与不脱轨的超导电流，永远闭合在超导体晶格内部。不从外部引一根电线，悬浮不费地府一度电！**

## 3. 地下长定子直线电机驱动（幽冥牵引所）

既然悬浮无阻，如何让总质量 $M \approx 10\text{ 吨}$ 的巨环周天巡游？

### 3.1 供电与电磁拓扑

* **凡插电者，深埋九泉**：所有三相变频驱动电缆与长定子线圈全部浇铸在地下暗槽的防水防潮绝缘仓内。
* **直线感应电机（LIM / LSM）**：
  * 定子：地下环形展开的三相绕组线圈，通以低频可变交流电，激发沿切线方向移动的行波磁场：
    $$B_{travel}(\theta, t) = B_0 \cos(p\theta - \omega t)$$
  * 转子：浮船底部安装轻量化高纯度铝制感应反应板（导电二次侧）。行波磁场在铝板中感应出涡流，产生洛伦兹推力 $F_{\theta}$：
    $$F_{\theta} = \frac{1}{2} \sigma A d \cdot s \cdot v_s B_0^2$$
    （其中 $s$ 为转差率，$v_s$ 为同步相速）。
* **物理视觉结果**：
  浮船本身是无源导体。地面上的人只能看到整座茶灯船凌空 20mm 悬浮在白雾之中，无接触、无火花、无机械轴承，如幽灵般自行匀速旋转。

## 4. 低温冷冻声学与柯本吉他破界共鸣（MTV Unplugged）

### 4.1 冠名标的与声学工况

* **1 号领航旗舰（黄道天枢位）**：
  供奉 **Kurt Cobain 1959 Martin D-18E 原声吉他**（全球拍卖纪录 601 万美元图腾）。
* **冷冻声学物理相变**：
  液氮挥发出的干燥低温冷氮气（$T \approx 150 \sim 200\text{ K}$）包裹吉他共鸣箱。
  * **木质素淬火晶化**：阿迪朗达克红云杉与洪都拉斯桃花心木的残余自由水升华，细胞壁在极低温下刚度急剧提升，杨氏模量 $E$ 增长约 $40\%$。
  * **声阻抗突变**：冷雾致密氮气介质与淬火木材形成独特的声学边界层，原声共鸣频率整体上移，高频泛音清冽如金石裂帛。

### 4.2 北坡水梯冲击波与机械击发机制

严禁使用现代电声拾音器与扬声器功放，全靠物理声学传导：
1. **地脉联动**：北坡变质量阿特伍德吊桶撞击忘忧重工 Duffing 神簧，产生 $f \approx 8\text{ Hz}$ 次声波地脉震颤。
2. **重力拨片击发**：地脉震击通过地下岩层传导至 1 号船位，触发悬浮船头机械惯性连杆，使得战国青铜音叉拨片以特定角度滑过吉他琴弦。
3. **降 E 调和弦（Drop-Eb）**：吉他自动完成一次柯本标志性的降 E 调扫弦，声音在 48 米圆环与白雾中激荡，为 16 分钟一次的周天巡礼宣告散场。

## 6. 物理引擎数值模型（TypeScript 离散化规范）

```typescript
export interface MaglevRingState {
  theta: number;       // 角位置 (rad) [0, 2pi)
  omega: number;       // 角速度 (rad/s)
  z: number;           // 悬浮垂直间隙 (m, 基准 0.02)
  vz: number;          // 垂直振动速度 (m/s)
  temperature: number; // 超导块温度 (K, 临界 93K)
  liquidN2Mass: number;// 液氮剩余工质 (kg)
}

export class AltarMaglevLanternEngine {
  readonly R = 24.0;             // 旋转半径 (m)
  readonly M_total = 10000.0;     // 浮环总质量 (kg)
  readonly I_rot = 5.76e6;       // 转动惯量 M * R^2 (kg·m²)
  readonly K_z = 2.5e6;          // 磁通钉扎垂直刚度 (N/m)
  readonly D_z = 1.2e4;          // 垂直磁阻尼 (N·s/m)
  readonly F_drive = 1200.0;     // 直线电机推力 (N)
  readonly gamma_air = 45.0;     // 空气粘滞阻力系数
  
  public state: MaglevRingState = {
    theta: 0.0,
    omega: 0.00654,              // 约 16 分钟旋转一整周 (2*pi / 960s)
    z: 0.02,                     // 20mm 磁浮高度
    vz: 0.0,
    temperature: 77.0,           // 77K 稳态
    liquidN2Mass: 500.0
  };

  public update(dt: number, seismicPulse: number): void {
    const s = this.state;
    
    // 1. 垂直磁通钉扎动力学 (受北坡水梯撞簧地脉震击扰动)
    const deltaZ = s.z - 0.02;
    const F_lev = -this.K_z * deltaZ - this.D_z * s.vz + seismicPulse * 5000.0;
    const az = F_lev / this.M_total;
    s.vz += az * dt;
    s.z += s.vz * dt;

    // 2. 切向圆周驱动与空气粘滞阻力
    const T_drive = this.F_drive * this.R;
    const T_drag = this.gamma_air * s.omega * this.R * this.R;
    const alpha = (T_drive - T_drag) / this.I_rot;
    
    s.omega += alpha * dt;
    s.theta = (s.theta + s.omega * dt) % (2 * Math.PI);

    // 3. 工质相变与冷雾消耗
    s.liquidN2Mass -= 0.005 * dt; // 持续挥发生成致盲白雾
  }
}
```
