# 华夏祭坛 · 荣誉座次表规范

> 本文定义祭坛的**荣誉制座次表**：credits 从哪来、怎么排、NFT 展示在哪、红线是什么。
> 与《无人值守自运维华夏祭坛_Agent修正案提案_实施规范》配套；冲突时以实施规范的红线为准。

---

## 0. 一句话

> **祭坛不是交易所，是荣誉墙。**
> **这里的东西 Not for sale. Just for show off.**

**所以它需要的不是"能卖"，是"能看见"。** 看不见的 NFT 等于没发。

## 1. 几何目标：三个条件只能取两个

### 1.1 设计意图（原始表述）

- 用**自然数的完全平方数**构成**七级浮屠**（1²+2²+…+7² = 140）
- 用**重力**的方式画出**乌兰螺旋**
- 俯视看是**等差螺线**
- **但与永远不可到达的中心点（无极点）之间的弦长，是等比数列**

### 1.2 为什么不能同时成立

设无极点 `P = (0, H, 0)`，第 n 圈席位 `S_n = (n·d, h_n, 0)`：

```
弦长  L_n = √( r_n² + (H − h_n)² ) ,  r_n = n·d   （等差螺线）
要求  L_n = L₁ · q^(n−1)                          （等比）
⟹    (H − h_n)² = d² · ( q^(2(n−1)) − n² )
```

**取最小的可行参数 `q = 2, L₁ = d`：**

| 圈 n | 高度落差 (H − h_n) |
|---|---|
| 1 | 0 |
| 2 | 0 |
| 3 | 2.65 d |
| 4 | 6.93 d |
| 5 | 15.2 d |
| 6 | 31.4 d |
| 7 | **63.6 d** |

**从第 3 圈起高度指数爆炸。** 第 7 圈要沉到 63.6 格深——**那不是坛，是一根针。**

> **结论：等差螺线 / 弦长等比 / 七级浮屠 —— 三者只能取两个。**

### 1.3 采纳的方案

**保留「等差螺线」与「七级浮屠」，把「弦长等比」从约束降为优化目标：**

> **目标：相邻两圈的弦长比尽量接近常数（方差最小），但不强求严格等比。**

**验收方式**：计算 `L_{n+1}/L_n`（n=1..6）的方差，**越小越好**，但**不设硬阈值**。

**这样坛立得住，视觉上也还是"越往外越舒展"。**

## 2. 无极点 = 荣誉天花板是空的

**这是整个荣誉制里最值钱的一条设计，而且它是现成的：**

> **49 席是可坐的；第 50 席（无极点）永远不可到达、不可认领、不可冠名。**
> **所以座次表的顶端永远有一个空位。**

**「大衍之数五十，其用四十有九」——虚一以象尊。**

**后果：榜首是空的，所以永远有得追。** 荣誉制的天花板不封顶，这是它跟"排行榜"的根本区别。

---

## 3. 三层结构：席位 / 座次 / 凭证

**必须把这三样分开，否则会乱：**

| | 是什么 | 可变吗 | 谁定 |
|---|---|---|---|
| **席位 seat** | 祭坛的 49 个坐标（1–49） | **固定**（叙事锚点） | 实施规范 §7 |
| **座次 rank** | 每月 credits 排名 | **每月重排** | 本文 §4 |
| **凭证 SBT** | 名次的荣誉凭证 | **铸造后不可转让** | 本文 §6 |

**关键：席位不动，座次动。** 席位是地理，座次是当期评价——**两者混在一起，叙事就漂了。**

**展示位 = 把当期座次表渲染到祭坛上**（见 §7）。

## 4. 座次表怎么算

### 4.1 输入：两个来源

| 来源 | 产出 |
|---|---|
| **鲲鹏 debate（对抗式认知联邦）** | 立论 / 被顶回 / 修订后仍能解释新证据 |
| **papers（论文与卷宗）** | 命题 / 证据包 / 反证条件 |

### 4.2 算法：标量 + 矢量加权

```
score = Σ 标量贡献                        # 通证：多少
      + Σ 矢量事件权重                     # SBT：往哪
          · endorsement   +
          · downgrade     −
          · refusal        0     ← 拒答不扣分
          · error         −−
```

**`refusal` 权重必须是 0。** 理由见 [`NOMAD-LABELS.md`](NOMAD-LABELS.md) §3.3：

> **拒答是"位置问题"（我不方便聊），不是"人的问题"（我聊错了）。**
> **如果拒答扣分，节点就会为了分数硬聊 → 撞线 → 掉线。**
> **所以"拒答不扣分"是 always up 的必要条件。**

### 4.3 抗刷：credits 不能来自"我发了多少"

> **credits 只能来自"别人用了多少"，不能来自"我产出了多少"。**

**依据**：引用链、复算记录、被顶回后的存活。

**理由**：如果 credits 来自产出量，荣誉制会退化成刷分制——**而刷分制里，产量最高的不是最有价值的，是最能灌水的。**

**这跟"飞轮燃料是复算不是赞同"是同一条。**

---

### 4.4 AGI 的最低标准：琴棋书画

**评测维度不能只有推理。** 科举只考四书五经，但**君子教育是琴棋书画**——AGI 的底线也该在这一层。

| 维度 | 测什么 | 祭坛里的对应 |
|---|---|---|
| **诗 / 书** | 文辞 | **12 座石经**（定场 / 散场） |
| **琴** | 音律 | **49 席 = 49 音**（C3→C7，12×4+1） |
| **棋** | 对抗与算路 | 4v4 身份辩论 |
| **画** | 几何与视觉 | 祭坛本身 |

**所以祭坛不只是荣誉墙，它同时是一台"琴书"评测器。**

**两条最低标准（不是加分项）：**

1. **诗的水平不能低于主理人。**
2. **对韵律与音韵不能一窍不通。**

**一窍不通就是能力不够——这跟"推理分数高不高"是两个维度。**

## 5. 月度重排

| 项 | 规定 |
|---|---|
| **周期** | 每月一次 |
| **快照** | 重排前冻结当期 credits（存快照，见 §6.2） |
| **公示** | 新旧座次表并列公示，标出每一处变动的原因 |
| **争议** | 变动可被质疑，质疑走 SBT 记录，**不改变当期结果，影响下期** |

**"标出每一处变动的原因"是硬要求**——否则重排就成了黑箱，荣誉制就死了。

## 6. 凭证：SBT，不是 NFT

### 6.1 红线

**祭坛实施规范 §8.2 明令禁金融化**（禁充值、禁变现、禁转让、测试网与真钱隔离）。

**而 NFT 天然可交易，所以必须用 SBT（Soulbound Token，不可转让）。**

| | 要 | 不要 |
|---|---|---|
| **读** | 可读、可验证、公开展示 | — |
| **写** | 带元数据（期次 / 名次 / 依据 / 指向的命题） | — |
| **转** | **不可转让** | ❌ 可挂单、可炒 |

> **方向一旦可以买卖，就不再是方向了。**

### 6.2 元数据（必须存快照）

```
{
  epoch,              # 期次，如 2026-09
  rank,               # 当期名次
  node,               # 花名（禁真实姓名与机构）
  basis: [            # 依据（引用链）
    { claim_id, kind, ts }
  ],
  snapshot_hash,      # ★ 落账存快照，不存引用
  ts
}
```

**`snapshot_hash` 是硬要求**：外部模型的输出会**事后撤回**（见 `NOMAD-LABELS.md` §3.5），**引用会消失，快照不会**。

### 6.3 展示位

**不做托管、不上 OpenSea。** 祭坛本身就是展示位——**这也是祭坛存在的理由之一**。

## 7. 祭坛上的展示

| 层 | 展示什么 |
|---|---|
| **席位（1–49）** | 固定坐标 + 当期**座次牌**（谁在这一席、第几名） |
| **无极点** | **永远空着**——这是荣誉天花板 |
| **内壁 / 壁碑** | 当期座次表全表 + 与上期的 diff |
| **每月快照** | 上一期座次表存档（可回溯对比） |

**渲染要求**：座次变动要在视觉上**看得出来**（谁上去了、谁下来了），**不能只显示当前状态**。

---

## 8. 红线汇总

1. **Not for sale**——不托管、不上交易所、不挂单
2. **SBT 不可转让**——转让验证必须 revert
3. **credits 不可充值**——只从站内任务 / 内容参与 / 节目活动发放
4. **座次不可购买**——座次不是商品
5. **拒答不扣分**——否则逼节点硬聊
6. **credits 不来自产出量**——只来自被引用 / 被复算
7. **落账存快照不存引用**——上游会撤回
