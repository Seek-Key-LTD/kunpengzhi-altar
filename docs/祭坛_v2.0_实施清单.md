# 华夏祭坛 v2.0：剩余实施清单

本清单只记录尚未交付的视觉、听觉与验收工作。公共入口已切换为三十分钟仪式；不再把公式、座次、物理状态或管理控件叠在画面上。

## 已落地

- 公共入口由后台式 HUD 改为黑场中的单一“入坛”动作。
- 时间轴固定为 180 + 840 + 420 + 311 + 49 = 1800 秒。
- 第 1 席 C2 至第 49 席 C6，严格每席一个半音；水外沉，音上升。
- 黑场与静默阶段禁用后台水流；熄灯及静默只保留 #00 的冷顶光。
- 星舰、座次标签、Rapier 读数、公式面板均退出公共画面。

## 下一轮：先完成“装置是真的在说话”

### 1. 双龙的可见性

- 水龙：把现有连续粒子流收束为逐席触发的水滴/水线，严格沿向外、向下的 Ulam 路径推进。
- 音龙：为每一个已触发席位留下随半音升高而收紧的对数螺线光迹；它必须与水龙同源、反向，而不是另加一条装饰线。
- 外圈十六盏茶灯只在 17:00 后低速转动；雾中一次只出现一句，不做可阅读的整页诗词。

验收：静音看画面也能读出“水往下走，音往上升”。

### 2. #00 无极点

- 为 #00 单独建模为吸光体（roughness .95、metalness .1、无自发光），而非“第 50 个座位”。
- 它不进入座位数组、不参与音高、不可点击、不可铸造。
- 只在 24:00 后由窄角冷色顶光显形；29:11 起除该光外完全静默。

验收：任何路径下都不能把 #00 当成可占有的席位或 NFT。

### 3. 声音与节奏

- 接入低通后的水声、翻斗链条声与低频空间混响，分别服从五个阶段的音量包络。
- 对 49 个 `Tone.Frequency('C2').transpose(n)` 做离线频率断言：n=0 为 C2，n=48 为 C6，且相邻比值为 `2^(1/12)`。
- 为导演验收提供本地加速回放；公共版本永远保持三十分钟，不暴露倍速按钮。

验收：首末音、49 秒静默和每阶段边界可被录音时间码复核。

## 第二轮：工程验收与管理面分层

### 4. 导演/工程入口（与公共入口隔离）

- 使用单独路由或受认证入口呈现拓扑、49 席、91 阴、Rapier 与相机调试；不得通过公共 query 参数裸露。
- 增加俯视正交相机截图测试：49 席投影为 7×7，边界误差 `e <= 1e-4`。
- Rapier 只验证斗、轴、传感器和水的可达性；物理失败须有明确日志，不得在公共画面兜底成 HUD。

### 5. 荣誉层接入

- 固定席位、月度座次、证据快照、SBT/NFT 展示拆为四个数据对象；公共仪式只读聚合结果。
- #00 永久排除在通证、NFT、成交、转让、预约和贡献统计之外。
- 后续接 ASN 时，将辩论证据、时间线快照和身份凭据链接到管理面，而非写进装置字幕。

## 发布门槛

1. 桌面 Chrome 与移动端各跑完一次完整 30 分钟录屏。
2. 黑场、49 席、16 灯、逆熄与 49 秒静默逐项勾验。
3. 无 WebGL 时给出静默降级页，不把报错或工程说明展示给访客。
4. 公共页面 DOM 中不出现 `Rapier`、`140`、`91`、`座次`、`NFT`、相机模式或调试按钮。
