## 一、 顶层声学与几何对账（数学模型修正）

### 1.1 阳坛四十九与阴格九十一（阴阳历法咬合）
* **总实体中子格（140 节点）**：
  $$\sum_{k=1}^7 k^2 = 1^2 + 2^2 + 3^2 + 4^2 + 5^2 + 6^2 + 7^2 = \mathbf{140}$$
  对应引力雪橇 7 层相控阵致密节点。
* **朝天暴露席位（49 席 / 阳面）**：
  $$\sum_{k=1}^7 \left( k^2 - (k-1)^2 \right) = (49-36) + (36-25) + \dots + (4-1) + 1 = \mathbf{49}$$
  自天穹正俯视抹平 Z 轴，投影严格等于 $7 \times 7 = 49$ 见方的大正方形。对应亡者七七四十九日下地府、完成幽冥迁徙之数。
* **深埋结构内部的阴格子（91 格 / 阴面）**：
  $$140 - 49 = \mathbf{91}$$
  若按太阳古历 364 天（52 周）核算：
  $$364 \div 4 = \mathbf{91 \text{ 天}}$$
  **91 正好是太阳在黄道上走过一个季度（春生、夏长、秋收、冬藏）的绝对天数！**
* **对账结论**：49 与 91 相加，不是任意搭积木，而是**亡者迁徙的幽冥时间（七七四十九）与活人仰观的黄道太阳时间（一季九十一日）在同一座物理建筑中严格咬合**。

### 1.2 十二平均律的连续群严格映射：49 音高节点与 48 半音步长
拒绝“48+1 凑数说”，严格按十二平均律物理公式落地：
$$f_n = f_0 \cdot 2^{n/12}, \qquad n = 0, 1, 2, \dots, 48$$

* **49 个音高节点，48 段半音距离**：恰好构成 **4 个完整八度（$4 \times 12 = 48$）**。
* **终极物理杀机**：
  * 第 0 号音（基准音，如 $C_2$）与第 48 号音（第 49 个节点，如 $C_6$）**同名（同为 C 音）**！
  * 频率相差整整 $2^4 = 16$ 倍。
  * **含义**：经过四次生死轮回（幼年、青年、中年、暮年），灵魂在声学上重回其最初的本名，但其振动频率已升华了 16 倍！
* **中央无极点（#00）的声学定义**：
  * **大衍之数五十，其用四十有九**：四十九者皆可鸣，唯有那一不鸣。
  * #00 不进入音阶、不冠名、不出售、不发声。它是所有振动得以生发的绝对虚空（真空基态）。

## 二、 三十分钟现场仪式导演台本（“来了先哭半小时”）

严禁在现场向观众解释数学公式。一个字都不要讲，完全交由纯物理、声学与光影的低频诱导。

```
时间轴 (00:00 - 30:00)
├── 00:00 - 03:00 [前3分钟]  绝对黑暗 · 机械绞盘 · 深渊水滴（无极点死寂）
├── 03:00 - 17:00 [14分钟]  水落花开 · 49席逐级点名 · 4个八度攀升
├── 17:00 - 24:00 [7分钟]   双龙显形 · 转经大茶灯 · 《茶史五绝赋》单行显影
├── 24:00 - 29:11 [5分11秒] 第49音绝响 · 全坛逐席熄灭 · 唯留#00天光
└── 29:11 - 30:00 [49秒]    四十九秒绝对死寂 · 宇宙复盘
```

### 幕一：00:00 – 03:00（深渊的机械声）
* **视觉**：全场纯黑，零光污染。中央 #00 无极点不设任何光源。
* **声效**：只有冰冷的青铜链条转动声、重力自翻斗被绞盘提上去的低沉摩擦声（Rapier3D 刚体模拟）、以及深渊水池回荡的滴水声。
* **心理机制**：剥夺视觉，将生理心率强制压入低频等待。

### 幕二：03:00 – 17:00（十四分钟的逐席点名）
* **水力激发**：翻斗蓄满，越过力矩阈值倾覆，重力流水顺阳龙水道下注。
* **声光级联**：
  * 水流不齐开，**流经哪一席，哪一席的花才幽幽泛起冷光，并激发由深层阴格编钟敲出对应音符**；
  * 14 分钟内，49 席依次被点亮、鸣响；
  * 音高从 $32\text{ Hz}$（次声波边缘，直击胸腔共振）顺阴龙一路爬升。
* **心理机制**：如阎罗点卯，每一声钟响都是一个生命的终章与留白。

### 幕三：17:00 – 24:00（双龙显形与两千年走马灯）
* **双龙交汇**：水在向下流，琴在向上拔。
* **走马灯启动**：外围十六面大茶灯缓缓自转，水汽氤氲。
* **文本呈现**：《茶史五绝赋》绝不全屏刷出，而是随水流节拍，一次仅在水雾中显影一句：
  > *“谁烹苦涩分天下，自古茶关锁塞垣……”*
* **心理机制**：人间的柴米油盐、边疆烽燧与宏大宇宙水流重叠，凡人一生的悲欢被完全置于历史长河中冲刷。

### 1.4 幕四：24:00 – 29:11（第四十九音的巅峰死寂）
* **同名绝响**：第 49 音撞响，那是高出 4 个八度的纯净高音，与最底层的基频产生跨越时空的同名谐振。
* **倒序熄灭**：随后，从第 48 席到第 1 席，繁花微光按照与开花完全相反的顺序，一盏一盏全部熄灭！
* **天光下泄**：万籁俱寂中，仅有头顶一道极细冷光垂直打在**中央 #00 无极点**上。空无一人，空无一花，无名无售。
* **心理机制**：走完全部 49 席的繁华与名字之后，猛然直面宇宙最根本的虚空——至此，无人能止住眼泪。

### 幕五：29:11 – 30:00（四十九秒绝对静默）
* 祭坛停止一切敲击，水流落入回收暗渠。
* **整整 49 秒的绝对静音（Silent Checksum）**。
* 30 分钟满，活人起步离场。

## 三、 Codex 工程交付接口指引

### 3.1 渲染管线 (Three.js)
* **Z 轴压平验证**：配置正交俯视相机 `OrthographicCamera` 时，确保 49 席网格与外围 $7 \times 7$ 包络框完全重合（$e \le 10^{-4}$）。
* **中央无极点**：材质使用深吸收率 `MeshStandardMaterial`（Roughness 0.95, Metalness 0.1, Emissive #000000），仅接受顶部特定定向聚光灯（SpotLight）。

### 3.2 动力学与碰撞 (Rapier3D Wasm)
* **重力翻斗**：配置 `RevoluteJoint` 旋转关节与非对称质心刚体，蓄水质量达到 $M_{\rm critical}$ 时自动失稳倾覆。
* **水流粒子**：使用碰撞球群沿乌兰方螺旋管道坡降下滑，跌落至席位传感器区域（Sensor Collider）触发声光回调。

### 3.3 声学引擎 (Tone.js)
* **频率计算**：严格按照 `Tone.Frequency("C2").transpose(n)` 绑定至 49 席，禁止使用离散硬编码近似。
* **空间残响**：挂载 `Tone.Reverb`（Decay 6.5s, PreDelay 0.08s）与 `Tone.Filter`（Lowpass 120Hz 用于次声波胸腔共鸣增强）。
