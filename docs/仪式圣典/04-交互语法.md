# 交互语法（#25）

> Issue: #25

## 一、公共正典（观礼中）

### 观众能做什么

- 移动视角（鼠标拖动 / 触摸滑动）
- 等待（仪式自动播放）

### 观众不能做什么

- 禁止 WASD/QE 飞行
- 禁止点击交互
- 禁止调整相机参数
- 禁止跳过幕次
- 禁止快进/快退

### 叙事含义

- 观众是**见证者**，不是参与者
- 仪式自动播放，观众只能观看
- 这是"失去解释权"的第一幕主题

## 二、Rabbit Hole（终场后内入）

### 观众能做什么

- 步行（沿轴移动）
- 凝视（注视某一层）
- 触碰（诗词显影）

### 观众不能做什么

- 禁止跳跃
- 禁止飞行
- 禁止刷分
- 禁止解谜

### 叙事含义

- 步行 = 时间的经过
- 凝视 = 理解的深度
- 触碰 = 个人的内入
- 这是"个人尺度"的体验，不是集体考核

## 三、禁止事项

- 禁止把 Rabbit Hole 退化成刷分或解谜清单
- 禁止把 49 席当成等级排行榜
- 禁止把 #00 当成可占有物
