# Sarazm 历史天象层技术规格（T1）

> Issue: #15
> 阶段：第一阶段（静态预计算天球 + Three.js 地貌遮挡）

## 1. 地理基线

| 参数 | 值 | 来源 |
|---|---|---|
| 地点 | Sarazm 遗址中心 | UNESCO World Heritage List #1141 |
| 纬度 | 39°30'28.4"N | UNESCO nomination |
| 经度 | 67°27'31.4"E | UNESCO nomination |
| 海拔 | 910 m | UNESCO nomination |
| 坐标系 | ENU（East-North-Up） | 本地地平坐标 |

## 2. 历史窗口

| 参数 | 值 | 说明 |
|---|---|---|
| 纪元 | 公元前 3000–2500 年 | 萨拉兹姆晚期 |
| 样本日期 | 冬至（约公元前 2800 年 12 月 21 日） | 第一版固定样本 |
| 岁差 | 需计算 | 从 J2000 推算到 epoch |

## 3. 时间映射

| 参数 | 值 | 说明 |
|---|---|---|
| 真太阳日 | 24 h | 物理真实 |
| 仪式时长 | 30 min | 压缩比 48:1 |
| 恒星日 | 23 h 56 min | 用于恒星旋转 |
| 时间真源 | `ritualElapsed` | 复用现有仪式时间轴 |

## 4. 天体清单

第一版至少支持：
- 星点背景（约 100 颗亮星）
- 北天极（岁差修正后）
- 太阳
- 月亮
- 主要星群/星座线（猎户座、大熊座、天蝎座）

## 5. 地貌层

- 泽拉夫尚河谷轴线
- 遗址台地
- 远山/盆地天际线
- 地平线轮廓：azimuth → horizonAltitude

## 6. 图层开关

| 图层 | 可独立开关 |
|---|---|
| 天球（星点/太阳/月亮） | 是 |
| 天空/大气 | 是 |
| 地貌（DEM 轮廓） | 是 |
| 祭坛本体 | 是 |

## 7. 工程约束

- 复用现有 Three.js 单渲染器
- 不引入第二个 WebGL canvas
- 不嵌入完整 Stellarium 引擎
- 公共入口不得出现经纬度/工程参数/调试 HUD
