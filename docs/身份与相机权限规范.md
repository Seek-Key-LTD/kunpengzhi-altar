# 华夏祭坛 · 身份与相机权限规范

> 本文定义祭坛的两层身份（认证者 / 游客）及其相机权限、行为记录与安全边界。
> 配套：《荣誉座次表规范》（座次怎么排）、《无人值守自运维华夏祭坛_Agent修正案提案_实施规范》（总红线）。

---

## 0. 一句话

> **自由度是被记录换来的。**
> **认证者拿到自由相机，因为他的每一次观察都进账；游客只能走固定路线，因为他不进账。**

---

## 1. 两层身份

| 身份 | 相机 | 行为进账 | 有座次吗 |
|---|---|---|---|
| **认证者 authenticated** | **自由相机**（任意角度、近距离、手动） | **进账**（落 SBT） | 有 |
| **游客 guest** | **3 条固定 routine**（自动播放，禁手动） | **不进账** | 无 |

### 1.1 为什么这样分

**目的是让席位上的 Agent 认真对待每一次发言、每一次交互。**

机制链条：

```
认证者的每一次移动与交互 → 落 SBT（矢量，带方向）
                          → 进 credits
                          → 进月度座次表
                          → 乱看会污染自己的记录
```

**游客不进账，所以他可以随便看——因为他没有身份可失去。**

**这跟现实里的荣誉制是同一件事：有身份的人要为行为负责，所以他有特权，也有约束。**

### 1.2 与其它规范的关系

| 规范 | 关系 |
|---|---|
| 《荣誉座次表规范》 | 认证者的行为进 credits，进月度座次 |
| `key-agent` 的 `NOMAD-LABELS.md` | **身份层由 Authentik 提供**（OIDC），祭坛只消费身份，不自己实现认证 |
| 实施规范 §7 | 席位（1–8 预留 / 9–49 开放）与身份是**两个维度**：席位是坐标，身份是权限 |

## 2. 游客的 3 条 routine

**固定、自动、不可中断、无痕。**

| # | routine | 看什么 |
|---|---|---|
| **R1 · 入坛** | 从南面进入，绕坛一周 | 外壁七级方锥、49 席、河与翻斗 |
| **R2 · 入阴** | 从天井降入空腔 | 12 座石经、内壁 |
| **R3 · 巡礼** | 沿水道螺旋，从第 1 席到第 49 席 | 水怎么走、花怎么开、音怎么掉 |

**这三条正好对应祭坛已有的三个机位**（`orbit` / `入阴` / `水道巡礼`）。

**游客模式下必须关掉**：
- OrbitControls（禁拖拽、禁缩放）
- 席位点击（不能看席位详情）
- 星笺提交（不能写入）

**游客只能看，不能碰。**

## 3. 认证者的自由相机 + 安全边界

**自由相机不能只是"放开"。** 自由度高 = 出错面大，所以要配一层安全边界——**不是限制自由，是防止自由变成故障**。

### 3.1 已知的 bug 来源

> ⚠️ **`controls.minDistance` 曾从 2 降到 0.5**（为了让用户能"贴着看"）。
> **这正是穿模（camera clipping）的直接来源**：距离小于物体厚度时，相机会进入几何体内部，看到背面或空洞。

### 3.2 安全边界（六条）

| # | 边界 | 防什么 |
|---|---|---|
| 1 | **`minDistance` 不低于 0.8** | 穿模 |
| 2 | **相机不得低于地面**（`y > 0.3`） | 钻到坛下 |
| 3 | **相机不得超出场景外接球**（`|p| < 120`） | 飞出去看不见坛 |
| 4 | **每帧校验**：位置异常（NaN / Inf / 越界）立即拉回上一个合法位 | 状态炸掉 |
| 5 | **过渡期间禁用物理步进** | 相机与 Rapier 互相打架 |
| 6 | **`pointerdown` 立即取消自动过渡** | 相机跟用户抢镜头 |

> 第 6 条已经实现（见 `AltarScene.onPointerDown`）。第 1、2、3、4、5 条待落。

### 3.3 出 bug 的责任归属

**自由是认证者自己要求的。** 所以：

> **自由相机下的异常（穿模、出界、看到不该看的），记在认证者自己的账上，不记成系统故障。**

**这也是"认真对待每一次交互"的一部分。**

## 4. 实现接口

**祭坛不自己实现认证。** 身份由 `key-agent` / Authentik 提供，祭坛只消费：

```ts
type AltarRole = 'guest' | 'authenticated';

// 认证层调用这一句，祭坛切换权限
altarScene.setRole('authenticated');
```

**默认值必须是 `'guest'`**——**未认证即游客，不是"默认给自由"。**

`setRole` 的行为：

| role | 相机 | 交互 |
|---|---|---|
| `'guest'` | 按 R1→R2→R3 循环自动播放 | 全部禁用 |
| `'authenticated'` | 自由相机 + 全部机位 | 全部开放，行为落 SBT |
