# RFC-007 终案：华夏祭坛“中空神索·双体变质量阿特伍德振子”物理动力学模型与实现规范

本规范面向物理引擎（如 Rapier3D、PhysX 或自定义 Runge-Kutta 积分器），对祭坛北坡水梯的机械拓扑、流体交换、非线性碰撞及离散数值解法进行严格约束。

---

## 1. 系统宏观拓扑与自由度约束

系统由顶端定滑轮、承力导流一体化中空主索、两只刚性轻量吊桶、底部非线性储能弹簧及顶/底流体边界构成。

```
          [顶端天车定滑轮 (y = 7.0)]
                 /       \
 (中空索内虹吸流) /         \ (中空索内虹吸流)
               /           \
         [ 桶 A ]         [ 桶 B ]
          y_A(t)           y_B(t)
            │                │
            ▼                ▼
     [ 底端神簧 A ]   [ 底端神簧 B ] (y = 0.0)
     [ 暗河补水池 ]   [ 暗河补水池 ]
```

### 1.1 广义坐标与运动学约束

* 标高区间：$y \in [0, H]$，基准全高 $H = 7.0\text{ m}$。
* 索长守恒约束（刚性中空索，忽略微小拉伸）：
  $$y_A(t) + y_B(t) = H$$
* 广义位移定义：令中位点 $y = H/2 = 3.5\text{ m}$ 为原点，定义系统一维广义自由度 $z(t) \in [-3.5, 3.5]$：
  $$y_A(t) = \frac{H}{2} + z(t), \quad y_B(t) = \frac{H}{2} - z(t)$$
  $$\dot{y}_A = \dot{z}, \quad \dot{y}_B = -\dot{z}$$
  $$\ddot{y}_A = \ddot{z}, \quad \ddot{y}_B = -\ddot{z}$$

---

## 2. 状态变量与质量传递微分方程

系统的总惯性质量随时间动态变化，状态向量包含空间运动与两桶装水量：
$$\mathbf{X}(t) = \big[ z(t), \, v(t), \, m_A(t), \, m_B(t) \big]^T \quad (v = \dot{z})$$

* 空桶净重：$m_0$
* 索体有效等效分布质量：$m_{rope}$
* 系统总等效惯性质量：
  $$M_{sys}(t) = 2m_0 + m_{rope} + m_A(t) + m_B(t)$$

### 2.1 索内闭环虹吸通量（连通器内流）

中空受拉索预充全满液体，两桶通过索内管道直接连通。流阻由索内径截面积 $A_p$、等效流阻阻尼系数 $C_d$ 及压强差决定：
$$\Delta P(t) = \rho g (y_A - y_B) = 2\rho g z(t)$$

设管内水体向 B 桶流动的质量流率为 $Q_{pipe}(t) = \dot{m}_{B \leftarrow A}$：
$$Q_{pipe}(t) = \text{sgn}(z) \cdot C_d A_p \sqrt{2g \vert{}z(t)\vert{}} \cdot \Theta(m_{high})$$
* 其中 $\Theta(m_{high})$ 为 Heaviside 阶跃函数，当高位桶水体排空时截断流率。

## 3. 边界非连续事件（离散相变触发）

物理引擎需在每个积分步中检测下列相变事件，并在瞬态应用脉冲与质量重置。

### 3.1 顶死点（$y \to H$）：挑舌掠水（剥离 5% 灌入乌兰 2 号位）

当桶 A 冲至顶死点（$z \ge 3.5 - \epsilon$ 且 $v \approx 0$）：
1. 触发水平圆周微位移导轨，固定挑舌切入液面：
   $$\Delta m_{skim} = 0.05 \cdot m_A(t)$$
   $$m_A(t^+) = m_A(t^-) - \Delta m_{skim}$$
2. 质量流向：$\Delta m_{skim}$ 沿刚性玉石滑槽导入祭坛天井，注水事件分发给乌兰螺旋逻辑。

### 3.2 底死点（$y \to 0$）：神簧反冲与暗河补水

当桶 B 触底（$z \ge 3.5 - \delta_{spring}$，$\delta_{spring}$ 为弹簧压缩量）：
1. **非线性神簧接触力：**
   $$F_{spring}(z) = -K \big( z - (3.5 - \delta_0) \big) - C_{spring} v$$
2. **暗河单向活瓣浸入补水：**
   底桶冲入暗河水面，动压差推开桶底活瓣，补足缺失质量：
   $$m_B(t^+) = m_B(t^-) + \Delta m_{skim}$$

## 4. 全局动力学方程（方程统合）

将重力失衡项、索内动量交换反冲项与底部反弹力统合至系统广义运动方程：
$$M_{sys} \dot{v} = \big[ m_B(t) - m_A(t) \big] g - \gamma_{air} v + F_{spring\_A}(z) - F_{spring\_B}(z) + F_{recoil}(Q_{pipe})$$

展开为适合数值积分的一阶 ODE 组：
$$\begin{cases} 
\dfrac{dz}{dt} = v \\ 
\dfrac{dv}{dt} = \dfrac{1}{M_{sys}(t)} \Big( [m_B - m_A]g - \gamma v + F_{spring\_net}(z) \Big) \\ 
\dfrac{dm_A}{dt} = -Q_{pipe}(t) - \delta(t - t_{top\_A}) \Delta m_{skim} + \delta(t - t_{bot\_A}) \Delta m_{replenish} \\ 
\dfrac{dm_B}{dt} = +Q_{pipe}(t) - \delta(t - t_{top\_B}) \Delta m_{skim} + \delta(t - t_{bot\_B}) \Delta m_{replenish} 
\end{cases}$$

## 5. 物理引擎实现代码（TypeScript / Rapier 伪代码参考）

可直接并入 `AltarScene.ts` 的离散物理更新步循环：

```typescript
export interface WaterLadderState {
  z: number;            // 广义位移 [-3.5, 3.5]
  v: number;            // 广义速度
  mA: number;           // 桶 A 储水量 (kg)
  mB: number;           // 桶 B 储水量 (kg)
}

export class AltarWaterLiftEngine {
  // 几何与物理常量
  readonly H = 7.0;             // 提升高度 (m)
  readonly m0 = 5.0;            // 空桶质量 (kg)
  readonly mRope = 1.2;         // 中空神索质量 (kg)
  readonly g = 9.80665;         // 重力加速度
  readonly K_spring = 15000.0;  // 底端神簧刚度 (N/m)
  readonly D_spring = 200.0;    // 弹簧阻尼 (N·s/m)
  readonly strokeLimit = 3.5;   // 半行程极限
  readonly CdAp = 0.00045;      // 索内通量节流常数
  
  public state: WaterLadderState = {
    z: 0.1,                     // 微扰启动初值
    v: 0.0,
    mA: 10.0,
    mB: 10.0
  };

  public update(dt: number): void {
    const s = this.state;
    const M_sys = 2 * this.m0 + this.mRope + s.mA + s.mB;

    // 1. 中空索内虹吸流计算
    let Q = 0;
    if (s.z > 0 && s.mA > 0) {
      Q = this.CdAp * Math.sqrt(2 * this.g * s.z);
    } else if (s.z < 0 && s.mB > 0) {
      Q = -this.CdAp * Math.sqrt(2 * this.g * (-s.z));
    }

    // 2. 底端神簧接触判定 (两端弹簧对偶)
    let F_spring = 0;
    const compressionA = (s.z + this.strokeLimit); // 桶 A 触底判定 (z -> -3.5)
    const compressionB = (this.strokeLimit - s.z); // 桶 B 触底判定 (z -> +3.5)

    if (compressionB < 0) { // B 压入底簧
      const penetration = -compressionB;
      F_spring -= (this.K_spring * penetration + this.D_spring * s.v);
    } else if (compressionA < 0) { // A 压入底簧
      const penetration = -compressionA;
      F_spring += (this.K_spring * penetration - this.D_spring * s.v);
    }

    // 3. 动力学加速度求解 (Newton-Euler)
    const F_gravity = (s.mB - s.mA) * this.g;
    const a = (F_gravity + F_spring) / M_sys;

    // 4. 半隐式欧拉积分 (Semi-implicit Euler)
    s.v += a * dt;
    s.z += s.v * dt;

    // 5. 质量交换积分
    s.mA -= Q * dt;
    s.mB += Q * dt;

    // 6. 极限死点相变检测 (挑舌截留与暗河注水)
    this.handleDiscretePhaseTransitions(s);
  }

  private handleDiscretePhaseTransitions(s: WaterLadderState): void {
    // 桶 A 达顶点，桶 B 扎入暗河
    if (s.z >= this.strokeLimit && s.v <= 0) {
      const skimmed = s.mA * 0.05; // 挑舌截流 5%
      s.mA -= skimmed;
      s.mB += skimmed;             // 底桶自暗河吞入对等补液
      this.triggerAudioTone('HUANG_ZHONG'); // 触发十二律吕音效
      this.dispatchUlamSpiralFlow(skimmed); // 注入乌兰螺旋 2 号位
    }
    // 桶 B 达顶点，桶 A 扎入暗河
    else if (s.z <= -this.strokeLimit && s.v >= 0) {
      const skimmed = s.mB * 0.05;
      s.mB -= skimmed;
      s.mA += skimmed;
      this.triggerAudioTone('LIN_ZHONG');
      this.dispatchUlamSpiralFlow(skimmed);
    }
  }

  private triggerAudioTone(note: string): void {

  }

  private dispatchUlamSpiralFlow(mass: number): void {

  }
}
```

## 6. 调谐与收敛基准

物理引擎在初始化该模块时，需满足以下稳定性判据：

1. **共振频率整定：** 调整 $K_{spring}$ 与通量节流常数 $C_d A_p$，使得单个半往复周期 $T/2$ 严格锁定为音乐节拍标准（如固定为 $2.00\text{ s}$，对应 60 BPM 下的两拍）。
2. **通量守恒阈值：** 索内流动耗时必须与单程运动时间严格重合，避免在两桶处于中位线 $z=0$ 擦肩时出现滞后逆流。
