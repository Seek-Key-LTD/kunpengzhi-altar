## 📐 核心数学、力学与声学架构

### 1. 大衍之数五十，其用四十有九
* **中央无极点（#00）**：点而不名，永不售卖，象征宇宙的第一因与系统的初始状态。
* **七级退台方坛**：自下而上分别为 7×7、6×6、5×5、4×4、3×3、2×2、1×1 的砖层堆叠。
* **暴露面积严格守恒**：
  $$\sum_{k=1}^{7} \left( k^2 - (k-1)^2 \right) = (49-36) + (36-25) + \dots + 1 = 49$$
  每一阶向上的暴露砖面恰好容纳一个朝天繁花席位。

### 2. 乌兰方螺旋律 (Ulam Spiral & 12-TET)
* **总控制律**：**水道即路径，路径即乐谱，乐谱即镜头，镜头即巡礼。**
* **十二平均律映射**：49 席严格对齐 4 个八度梯度的 12-TET 编钟与和声音色（Tone.js 物理合成）。
* **水流触发节拍**：重力提斗上水至顶层，顺乌兰方螺旋逐席下行灌溉，水落处激发生命繁花音律。

### 3. 十六面转经走马大茶灯
* 祭坛外围环绕 16 面巨型转经走马灯屏，刻录锁侠原著 **《茶史五绝赋》**（16 章、256 句、1280 言一韵到底）。
* 支持「静止 / 极缓 / 慢游」三档转速控制与双栏对位精读。

## 🛠️ 技术栈与工程拓扑

| 层次 | 核心技术 | 职责说明 |
| :--- | :--- | :--- |
| **渲染层 (3D View)** | Three.js (r174) | PBR 材质、动态阴影、暗黑金石调色、相机 6-DoF 平滑巡礼 |
| **物理引擎 (Physics)** | `@dimforge/rapier3d-compat` (Wasm) | 水滴刚体碰撞、重力翻斗提水、缆绳滑轮动力学仿真 |
| **声学引擎 (Audio)** | Tone.js | 12-TET 编钟合成器、回声总线与空间混响 |
| **应用与组件 (UI)** | React 19 + TypeScript + Vite | 席位交互面板、经卷弹窗、走马灯全屏研读、合规自查 |
| **边缘交付 (Edge)** | Cloudflare Pages / Workers | 全球静态与 WebGL 资产毫秒级分发 (`altar.git4ta.fun`) |

## 🚀 本地开发与构建部署

### 环境要求
* Node.js >= 18.0.0
* npm >= 9.0.0

### 安装依赖
```bash
git clone https://github.com/Seek-Key-LTD/kunpengzhi-altar.git
cd kunpengzhi-altar
npm install
```

### 启动本地开发服务器
```bash
npm run dev
```
打开浏览器访问 `http://localhost:5173/`。

### 构建生产制品
```bash
npm run build
```
输出位于 `dist/` 目录。

### 部署到 Cloudflare Pages
```bash
npm run deploy
```
