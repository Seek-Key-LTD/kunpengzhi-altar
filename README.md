## 📐 核心数学、力学与声学架构

### 1. 大衍之数五十，其用四十有九（七七四十九天生死度量）
* **中央无极点（#00）**：点而不名，永不售卖，象征宇宙的第一因与系统的初始虚空。
* **七级退台方坛**：自下而上分别为 7×7、6×6、5×5、4×4、3×3、2×2、1×1 的砖层堆叠。
* **正投影暴露面积严格守恒**：
  $$\sum_{k=1}^{7} \left( k^2 - (k-1)^2 \right) = (49-36) + (36-25) + \dots + 1 = \mathbf{49}$$
  无论 Z 轴立面如何起伏，**自天穹正俯视向下压平，就是一个规整的 $7 \times 7 = 49$ 大正方形**。
* **七七四十九天**：人死之后七七四十九天下地府，四十九席朝天繁花，恰好收纳四十九份人间愿力与魂引。

### 2. 140 阳坛与 91 阴格（深埋地下的黄道之圆）
* **四角锥总砖数（140 节点）**：
  $$\sum_{k=1}^{7} k^2 = 1^2 + 2^2 + 3^2 + 4^2 + 5^2 + 6^2 + 7^2 = \mathbf{140}$$
  对应引力雪橇 7 层相控阵阵列的 140 颗致密节点。
* **深埋地底的 91 个阴格子**：
  $$140 - 49 = \mathbf{91}$$
  若按太阳古历 364 天（52 周）核算：
  $$364 \div 4 = \mathbf{91 \text{ 天}}$$
  **91 正好是太阳在黄道上走过一个季度（春生、夏长、秋收、冬藏）的绝对天数！**
* **坛虽方，内蕴圆**：外人看的是方坛台阶，唯有懂得数数的人数出这 91 个深埋的阴格，数出的才是天地不息的**黄道之圆**！

## 🚀 本地开发与构建部署

### 环境要求
* Node.js >= 18.0.0
* npm >= 9.0.0

### 安装依赖
```bash
git clone https://gitea.capitaltrain.cn/seekkey/kunpengzhi-altar.git
cd kunpengzhi-altar
npm install
```

### 启动本地开发服务器
```bash
npm run dev
```
打开浏览器访问 `http://localhost:5173/`。

### 构建生产制品
```bash
npm run build
```
输出位于 `dist/` 目录。

### 部署到 Cloudflare Pages
```bash
npm run deploy
```
